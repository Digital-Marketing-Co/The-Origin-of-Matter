## Scientific scope
This milestone develops the structural-variation and Indigenous-reference frontier identified in v339-v340. It uses Indigenous Australian population-scale long-read sequencing as a methodological blueprint while explicitly preventing transfer of population-specific numerical claims to Indigenous-American populations.

### Six-level hierarchy
1. **Long-read observation** — kilobase-scale reads resolve repeats and complex structural alleles.
2. **Structural-variant cataloguing** — insertions, deletions, duplications, inversions, CNVs and repeat expansions become first-class population variables.
3. **Community-scale population structure** — variant frequencies differ among Indigenous communities and cannot be represented by one proxy population.
4. **Pangenomic representation** — graph references encode alternative haplotypes and reduce linear-reference bias.
5. **Clinical interpretation** — population-aware references improve classification of rare and disease-associated variation.
6. **Community-governed genomic infrastructure** — data sovereignty, consent, access control and benefit-sharing are integrated with reference design.

## Deeper hierarchy
Long-read DNA → ONT/PacBio sequencing → T2T alignment → large indel discovery → SV calling → CNV analysis → tandem-repeat variation → mobile-element variation → community-specific variants → allele-frequency estimation → reference bias → pangenome graphs → haplotype phasing → clinical interpretation → disease repeat loci → broad/deep sampling → data sovereignty → controlled access → community benefit → community-governed population reference.

## Primary-source anchors
- Reis et al., **Nature 624 (2023) 602-610** — 121 Indigenous Australian long-read genomes; 159,912 SVs; 136,797 large indels; 156 CNV regions; substantial community-specific variation; National Centre for Indigenous Genomics partnerships.
- National Centre for Indigenous Genomics — frameworks emphasizing community leadership, participation and data sovereignty.
- Schloissnig et al., **Nature 644 (2025) 442-452** — 1,019 long-read genomes across 26 population groups; >100,000 sequence-resolved biallelic SVs and ~300,000 multiallelic tandem-repeat loci.
- Castro e Silva et al., **Nature 653 (2026) 134-145** — 128 high-coverage Indigenous-American genomes; extensive previously uncharacterized SNV diversity; structural variation not assessed.
- Human Pangenome Reference Consortium — graph/pangenome framework for multi-haplotype representation.

## Evidence firewall
- A complete linear reference does **not** capture all clinically important human variation.
- One Indigenous community cannot stand in for an entire continent.
- Short-read high coverage is not equivalent to long-read sequencing for repeats and SVs.
- More unrestricted data sharing is not automatically better science.
- Genomic sovereignty is compatible with reproducible research through governed access.
- Indigenous Australian variant counts are a methodological blueprint, not numerical proxies for Indigenous-American populations.
