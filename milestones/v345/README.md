## Six-level hierarchy
1. **Centromere epigenetic identity** — DNA methylation and CENP-A define stable centromere chromatin.
2. **Kinetochore mechanics** — centromeric chromatin organizes the chromosome-spindle interface and error correction.
3. **Segregation pathology** — centromere/kinetochore defects raise aneuploidy and genome-instability risk.
4. **Structural-variant diagnostics** — long reads and orthogonal mapping technologies resolve disease-causing rearrangements.
5. **Population structural genetics** — large long-read cohorts move SVs into association, selection and disease-susceptibility analysis.
6. **Clinical pangenome interpretation** — population-aware references reduce false positives and improve interpretation of complex genomic regions.

## Evidence firewall
- Centromere sequence alone does **not** fully determine centromere function; CENP-A chromatin and methylation matter.
- Centromere methylation change is **not automatically disease-causing**; magnitude, tissue and context matter.
- Aneuploidy does **not** imply cancer in every case.
- A structural variant detected by long reads is **not automatically pathogenic**.
- Long-read sequencing does **not** eliminate the value of orthogonal technologies such as optical genome mapping.
- A population pangenome improves reference quality but does **not** establish variant causality by itself.
