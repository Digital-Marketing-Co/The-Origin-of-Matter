## Archive integrity rule

A milestone is only called **persistently archived** after the exact raw file has been independently re-found or read back from persistent storage. A generated or preflighted runtime PDF is not automatically an archived PDF. Missing historical binaries remain visible recovery facts and must not be silently represented as present.
