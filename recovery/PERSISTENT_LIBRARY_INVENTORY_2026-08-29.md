## Recovery significance

The 357-page v132 PDF is currently the highest exact, byte-verifiable continuous encyclopedic master located in the persistent ChatGPT Library during this audit. Later work was generated as many standalone milestones, but not every later binary PDF was persisted. The project must therefore distinguish:

1. **Exact persistent binary** — a PDF whose bytes are retrievable and hash-verifiable.
2. **Reconstructible milestone** — scientific/textual work whose content and metadata survive in conversation/project records but whose exact PDF binary may have expired.
3. **Temporary generated artifact** — a runtime `/mnt/data` or `sandbox:` file that must not be treated as archived until copied into persistent storage.

## Permanent archive rule

No future milestone should be called "archived" until its persistent GitHub and/or Drive copy has been independently read back or otherwise verified. Temporary ChatGPT attachment URLs are delivery conveniences only, not archival storage.
